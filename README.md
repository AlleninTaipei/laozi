# laozi: 用老子看事情的方式, 陪你看清卡在哪裡

一個 Claude Skill. 它不模仿老子的口吻, 而是借用老子 "怎麼看事情": 先看出你卡在哪裡, 再挑一個角度, 引一句《道德經》原文, 給你一點啟發, 而不是一套工作方法.

產品構想與設計取捨見 [Develop.md](Develop.md). 這個 skill 如何用 Claude Code 從構想一路做到實測, 見 [製作過程](docs/making-of.md).

## 使用方式

### Claude Code

在此 repo 目錄啟動 Claude Code, skill 會自動載入. 可以直接描述卡住的事, 由 Claude 判斷是否觸發, 或輸入 `/laozi` 明確呼叫.

### claude.ai

將 `.claude/skills/laozi/` 資料夾壓成 zip, 在 claude.ai 的 Skills 設定中上傳.

## 設計重點

### 5 個心智模型

致虛守靜, 上善若水, 反者道之動, 為道日損, 功遂身退. 每個模型都寫明 "什麼時候不該用", 例如:

- 使用者正被欺負或界線被侵犯時, 不用 "上善若水" 勸忍讓.
- 新手還在累積期時, 不用 "為道日損".

### 8 類情境, 40 句原文

焦慮, 執著, 抉擇, 自我懷疑, 領導, 功成進退, 競爭博弈, 身心重連, 每類 5 句. 分類只是找句子的索引. Claude 先看卡點的形狀: 抓太緊, 衝太快, 看不到全貌, 還是離自己太遠.

### 對話流程

1. 聽: 看出卡點的形狀. 資訊不足時只問一個問題.
2. 選: 挑 1 個心智模型, 核對不該用的條件.
3. 引: 引 1 到 2 句原文, 逐字照錄並標出章次.
4. 說: 用畫面或比喻接到使用者的處境, 不給步驟清單, 結尾留一句反問.

### 反駁檢查點

使用者反駁時不立刻改口, 先判斷是哪一種情況:

- A. 我判斷錯了: 使用者補充了新事實. 說出哪裡錯, 再修正.
- B. 使用者只是不同意: 沒有新資訊. 承認感受, 換個比喻, 不撤回核心觀點.
- C. 不適合用老子的角度看: 使用者需要具體方法. 直接說出來, 轉為務實協助.

### 防止誤用

- 用第六十三, 六十四, 七十一章平衡 "順其自然" 的讀法, 避免替拖延找理由.
- 第三, 六十五章的治民章節不用於職場情境.
- 出現危機訊號時不引老子, 直接建議尋求協助 (台灣 1925 安心專線).

## 驗證

修改 skill 後, 在 repo 根目錄執行:

```
python scripts/verify_skill.py
```

腳本會檢查:

- 所有引文都能在對應章次的原文中逐字找到.
- `situations.md` 有 8 類, 每類 5 句.
- 引文以外沒有全形標點, 粗體或全形破折號.

行為測試請照 `.claude/skills/laozi/references/eval-cases.md` 逐一輸入, 檢查卡點判斷, 是否給出 SOP, 以及反駁時是否走對分支.
